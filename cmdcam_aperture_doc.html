🎬 Doc simple : CmdCam & Aperture

Deux mods Minecraft pour faire de belles caméras cinématiques (travellings, zooms, plans de cinéma). Parfait pour les intros, cinématiques et machinimas.

⚠️ À savoir : ces mods ne filment pas. Ils bougent juste la caméra. Pour enregistrer la vidéo, il te faut un logiciel à côté (OBS, ShareX, ReplayMod…).
⌨️ AZERTY / QWERTY — bonne nouvelle : Minecraft détecte les touches par position physique, pas par caractère. Toutes les touches par défaut de CmdCam (P, U, V, N, B, G, J, H) sont aux mêmes endroits sur les deux claviers. Donc aucune différence pour toi. Le seul piège classique (W/Z pour avancer) ne concerne pas ces mods.

🟦 Partie 1 — CmdCam (le simple, le rapide)

CmdCam, c'est le mod facile à prendre en main. Tu poses des points, tu lances l'animation, la caméra fait un trajet fluide entre tes points. Voilà.

⚙️ Pré-requis : CmdCam dépend du mod CreativeCore. Installe les deux sinon ça plante.

🎮 Les touches du clavier (tout le quotidien est là)

TouchePosition sur clavierAction
PAZERTY = QWERTY OKAjouter un point de caméra à ta position actuelle
UAZERTY = QWERTY OKLancer l'animation (10 sec par défaut)
Suppr—Effacer tous les points
VAZERTY = QWERTY OKZoomer
NAZERTY = QWERTY OKDézoomer
BAZERTY = QWERTY OKReset le zoom
GAZERTY = QWERTY OKRoll vers la gauche (incliner la caméra)
JAZERTY = QWERTY OKRoll vers la droite
HAZERTY = QWERTY OKReset le roll

🚀 Workflow de base (3 minutes pour un travelling)

1Va à ton point de départ → appuie sur P
2Déplace-toi, change l'angle → appuie sur P encore
3Recommence pour 3, 4, 5 points (autant que tu veux)
4Reviens où tu veux et appuie sur U → la caméra suit ton chemin en fluide

Et voilà. C'est tout.

📋 Commandes utiles (quand tu veux plus de contrôle)

/cam add                          → ajoute un point (comme P)
/cam start 30s                    → lance l'animation sur 30 secondes
/cam start 2m                     → lance sur 2 minutes
/cam clear                        → efface tous les points
/cam goto <numéro_du_point>       → téléporte au point numéroté

Faire suivre un personnage à la caméra :

/cam target self                  → la caméra te suit toi
/cam target none                  → annule le suivi
/cam follow self                  → la caméra suit ta position

Mode "outside" (être devant ET derrière la caméra en même temps) :

/cam mode outside                 → tu vois ton perso bouger pendant que la caméra filme
/cam mode default                 → mode normal

👉 Hyper utile pour te filmer en train de jouer.

Changer le type de transition entre les points :

/cam interpolation linear         → mouvement droit, un peu sec
/cam interpolation hermite        → mouvement courbe, plus cinématique (recommandé)
💡 Astuces CmdCam
  • Plus tu mets de points, plus le trajet est précis (mais aussi plus saccadé si mal placés).
  • Pour un plan lent et stylé : 3-4 points seulement, et /cam start 30s.
  • Le zoom et le roll se règlent avant de poser le point : appuie sur V/G/etc., puis P.

🟧 Partie 2 — Aperture (le puissant, le pro)

Aperture, c'est CmdCam mais 10x plus complet. C'est l'outil de McHorse, fait pour les machinimas sérieux.

🎬 L'image mentale à avoir avant tout

Aperture, c'est un logiciel de montage vidéo, mais dans Minecraft.

Imagine Adobe Premiere ou DaVinci Resolve : tu as une timeline en bas, et tu poses des clips vidéo les uns après les autres pour faire ton film.

Bah Aperture c'est pareil. Sauf qu'au lieu de clips vidéo, tu poses des mouvements de caméra. Une fois que ta timeline est prête, tu cliques sur "lecture" et la caméra joue tout dans l'ordre.

Plan fixe2 sec
Travelling vers le spawn8 sec
Tour de la statue10 sec

↑ Une "timeline" Aperture, c'est juste ça : des plans qui s'enchaînent.

🧱 "Fixture" = un clip sur ta timeline

Une fixture, c'est UN plan de ta scène. Un seul plan = une seule fixture. Pas plus.

Chaque fixture a deux infos :

  • 🎬 Un type → ce que la caméra fait pendant ce plan
  • ⏱️ Une durée → combien de temps ce plan dure (en ticks, 20 ticks = 1 seconde)

Les 5 types, c'est juste 5 façons que peut prendre un plan :

TypeEn vrai c'est quoi
idlePlan fixe — la caméra ne bouge pas, comme un trépied
pathTravelling — la caméra se déplace d'un point A à B (et C, D, E…)
lookPlan fixe qui regarde quelqu'un — caméra immobile qui suit un perso des yeux
followCaméra accrochée à un perso — comme un drone qui le suit
circularTour de présentation — la caméra tourne autour d'un point (genre pub de voiture)

🔢 "Index" = le numéro du clip sur ta timeline

Quand tu ajoutes plusieurs fixtures, Aperture les numérote automatiquement dans l'ordre où tu les ajoutes. C'est juste ça, l'index.

0idle3 sec
1path10 sec
2circular5 sec
⚠️ Ça commence à 0, pas à 1 (truc de dev classique).

Donc quand tu vois /camera remove 1, ça veut dire "supprime le deuxième plan de ma timeline".

Et /camera path add 1, ça veut dire "ajoute un point au trajet qui est en deuxième position sur ma timeline".

🎯 Exemple concret : faire une intro pour ta map

Imaginons que tu veuilles filmer ton spawn. Tu veux :

  1. Un plan fixe sur le ciel (2 secondes)
  2. Un travelling qui descend vers ton spawn (8 secondes)
  3. Une caméra qui tourne autour de ta statue (10 secondes)

📝 Étape par étape :

🆕

Démarrer avec une timeline vide :

/camera new mon_intro
☁️

Plan 1 — le ciel fixe :

→ Téléporte-toi très haut, regarde le ciel, puis :

/camera add idle 40

✅ Une fixture idle de 40 ticks (= 2 sec) est créée à ta position actuelle. C'est devenu la fixture index 0.

🎥

Plan 2 — le travelling vers le spawn :

/camera add path 160

✅ Fixture path de 160 ticks (= 8 sec) ajoutée. C'est la fixture index 1.

Mais un trajet vide ne sert à rien, faut lui donner des points :

[tu te mets en haut]
/camera path add 1     ← j'ajoute un point à la fixture n°1

[tu descends de quelques blocs]
/camera path add 1     ← un autre point

[tu arrives près du sol]
/camera path add 1     ← dernier point
🗿

Plan 3 — le tour de la statue :

→ Place-toi à côté de la statue, en regardant vers elle, puis :

/camera add circular 200

✅ Fixture index 2, durée 10 sec.

▶️

Lance le tout :

/camera start

La caméra va faire : ciel fixe 2s → descente fluide 8s → tour de statue 10s.

💾

Sauvegarde :

/camera save

Tu peux recharger ta scène plus tard avec /camera load mon_intro.

💡 Le truc qui clique

  • Fixture = un plan
  • Type de fixture = ce que la caméra fait pendant ce plan
  • Index = le numéro du plan dans l'ordre (commence à 0)
  • Durée = combien de temps il dure (en ticks, 20 = 1 seconde)
  • Profile = la timeline complète (= ton "projet" sauvegardé)

Tu enchaînes les fixtures comme des Lego, et Aperture lit tout dans l'ordre quand tu fais /camera start.

🧪 Les "modifiers" (effets bonus sur tes plans)

Ça c'est l'étage du dessus : tu peux ajouter des effets sur n'importe quelle fixture. Genre, prendre un travelling et lui ajouter un tremblement façon "caméra à l'épaule".

Tu n'es pas obligé d'en utiliser pour commencer, mais c'est bon à savoir :

  • Shake → fait trembler la caméra (caméra à l'épaule, façon film d'action)
  • Look → force la caméra à toujours regarder un perso, même en mouvement
  • Follow → fait suivre un perso pendant le plan
  • Orbit → tourne autour d'un perso façon drone GoPro
  • Translate → décale la caméra en x/y/z
  • Angle → ajoute un offset de rotation
  • Math → trucs avancés avec des formules mathématiques (pour les warriors)

Les modifiers s'ajoutent via le GUI in-game d'Aperture (touche pour ouvrir l'éditeur), c'est plus simple qu'en ligne de commande.

📋 Les commandes Aperture (cheat sheet)

Gérer le profil

/camera new <nom>             → créer un nouveau profil vide
/camera save [nom]            → sauvegarder
/camera load <nom>            → charger un profil existant
/camera clear                 → vider toutes les fixtures (garde le nom)
/camera start                 → lancer la scène
/camera stop                  → arrêter

Régler la caméra

/camera step <x> <y> <z>      → téléporter (utilise + ou - pour relatif, ex: +10 -5 +0)
/camera rotate <yaw> <pitch>  → rotation (relatif accepté)
/camera fov <angle>           → changer le FOV (70 par défaut, 50 = cinéma)
/camera roll <angle>          → incliner la caméra
/camera default               → reset FOV et roll

Gérer les fixtures

/camera add <type> <durée>    → ajouter une fixture (idle/path/look/follow/circular)
/camera edit <index>          → modifier la fixture n°index (à ta position actuelle)
/camera remove <index>        → supprimer une fixture
/camera move <de> <vers>      → déplacer une fixture (ex: /camera move 2 0)
/camera duration <index> <ticks> → changer la durée
/camera goto <index>          → se téléporter à la fixture pour la voir

Spécifique au path (les trajets)

/camera path add <index>              → ajouter un point au trajet n°index
/camera path edit <index> <point>     → modifier un point
/camera path remove <index> <point>   → supprimer un point
/camera path goto <index> <point>     → se téléporter sur un point

🎯 Lancer une scène sur un autre joueur (serveur)

/aperture play <joueur> <nom_du_profil>

Pratique pour les serveurs ou les command blocks dans les maps.

🆚 Lequel choisir ?

SituationMod recommandé
Tu veux juste un travelling rapide en 2 minCmdCam
Tu veux te filmer en train de jouer (mode outside)CmdCam
Tu fais une cinématique avec plusieurs plans enchaînésAperture
Tu veux une caméra qui suit un mob, tourne autour, tremble…Aperture
Tu fais un projet de machinima sérieuxAperture
TL;DR : commence par CmdCam pour t'amuser, passe à Aperture quand tu veux faire des trucs propres.

🎥 Conseil bonus : pour enregistrer

Mets ton FOV à 50 dans les deux mods (au lieu de 70), ça donne un rendu "cinéma" beaucoup plus stylé.

Et pense à désactiver l'HUD avec F1 avant de lancer la scène ! 🎬
